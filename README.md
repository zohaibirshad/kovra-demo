# Kovra – Live Demo

This repository hosts the **live demo** of **Kovra – Creative Agency & Portfolio HTML Template**, available on ThemeForest.

- Live demo: https://harrydeau.github.io/kovra-demo/
- Documentation: https://harrydeau.github.io/kovra-demo/documentation/

The demo uses original abstract placeholder artwork for preview purposes only. Images are not included in the purchased download.
Built with Bootstrap 5, SCSS, vanilla JS, GSAP + ScrollTrigger and Lenis.
