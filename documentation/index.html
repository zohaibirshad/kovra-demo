Kovra - Creative Agency & Portfolio HTML Template

Thank you for purchasing Kovra! Kovra is a dark, motion-rich HTML5 template for digital agencies, studios, freelancers and creative professionals. It is built with Bootstrap 5, SCSS, vanilla JavaScript (no jQuery), GSAP + ScrollTrigger and Lenis smooth scrolling, and ships with an optional light mode.

This guide explains how to set up, edit and customize the template. If something is unclear, please see Support.

  • 16 HTML pages including 3 home variants
  • Dark design with a one-click light mode (remembered per visitor)
  • Preloader, word-by-word text reveal, magnetic buttons, custom cursor, marquees, image hover reveal, clip-path image reveals, parallax, counters, pinned horizontal gallery
  • Fully responsive, keyboard accessible, respects prefers-reduced-motion
  • W3C-valid HTML, organized SCSS, well-commented modular JavaScript

Getting started

1. Unzip the package

After downloading from ThemeForest, unzip the main file. You will find:

kovra/
├── template/        ← the website (upload the contents of this folder)
├── documentation/   ← this guide
└── README.txt

2. Preview locally

Open template/index.html in a modern browser. Everything works straight from the file system. For the most accurate preview (and to test the contact form endpoint) we recommend a local server, for example the VS Code “Live Server” extension, or:

cd template
npx serve .          # or: python3 -m http.server 8000

3. Upload

Upload the contents of the template/ folder to your hosting (public_html, www, etc.) with FTP or your host's file manager. The assets/scss/ folder and package.json are only needed for development and can be left out of the upload.

HTML layout

Every page follows the same skeleton, with clear comments in the source:

<a class="skip-link" href="#main">Skip to content</a>
<div class="preloader">…</div>          <!-- optional -->
<div class="cursor">…</div>             <!-- optional -->
<header class="site-header">…</header>
<div class="offcanvas mobile-menu">…</div>
<main id="main"> … sections … </main>
<footer class="site-footer">…</footer>
<!-- vendor scripts, then assets/js/main.js -->

Navigation

The desktop menu is inside <nav class="main-nav">; the mobile menu is the Bootstrap offcanvas #mobile-menu. When you add or rename a page, update both menus (search the page source for main-nav and mobile-nav). Mark the current page link with aria-current="page".

Logo

The logo is a text wordmark (<a class="logo">Kovra<span>.</span></a>). To use an image instead, replace the text with <img src="assets/images/logo.svg" alt="Your brand" width="120" height="32">.

Removing the preloader or cursor

Delete the .preloader or .cursor element from the page. The JavaScript detects their absence automatically.

Colors & color modes

Colors are defined once in assets/scss/abstracts/_variables.scss and output as CSS custom properties (--kv-*) for the dark and light themes.

Option A - without a build step (CSS custom properties)

Add a small override after style.css, e.g. in a new assets/css/custom.css:

:root, [data-theme="dark"] {
  --kv-accent: #ff5c8a;       /* brand accent */
  --kv-accent-text: #ff5c8a;  /* accent used for text on dark backgrounds */
  --kv-bg: #0a0a12;
}
[data-theme="light"] {
  --kv-accent-text: #b0003a;  /* darker accent so text stays readable (WCAG AA) */
}

Option B - with SCSS

Edit $kv-accent, $kv-accent-light, the $kv-dark and $kv-light maps, then compile (see SCSS).

Custom propertyUsed for
--kv-bg, --kv-bg-soft, --kv-surfacePage background, alternate sections, cards
--kv-text, --kv-mutedMain and secondary text
--kv-borderHairlines and borders
--kv-accent, --kv-accent-inkAccent backgrounds and the text placed on them
--kv-accent-textAccent-colored text and links (darker in light mode)
--kv-invert-bg, --kv-invert-textInverted blocks (preloader, featured pricing card)

Light / dark mode

  • Dark is the default: <html data-theme="dark">. To make light the default, change it to data-theme="light" (and data-bs-theme="light") on every page.
  • Any button with data-theme-toggle switches the mode. The choice is saved in localStorage (key kovra-theme) and applied before first paint by theme-init.js.
  • To remove the toggle, delete the .theme-toggle button.

Fonts

Kovra uses two Google Fonts, both under the SIL Open Font License 1.1 and self-hosted in assets/fonts/ (no requests to Google, better privacy and performance):

  • Syne (display headings), variable weight 400-800
  • Manrope (body text), variable weight 200-800

To change fonts: add your @font-face rules in assets/scss/base/_fonts.scss (or load a Google Fonts stylesheet in the <head>) and update the variables, or override at runtime:

:root {
  --kv-font-display: "Space Grotesk", sans-serif;
  --kv-font-body: "Inter", sans-serif;
}

Optional (live server only): preload the main font files for faster first render by adding these tags to each page's <head>. Font preloads are not included by default because browsers block them when a page is opened directly from the file system (file://).

<link rel="preload" href="assets/fonts/syne/syne-latin-wght-normal.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preload" href="assets/fonts/manrope/manrope-latin-wght-normal.woff2" as="font" type="font/woff2" crossorigin>

SCSS & compiling

The compiled assets/css/style.css is included, so SCSS is optional. To work with SCSS you need Node.js 18+:

cd template
npm install          # installs Dart Sass (dev dependency)
npm run watch        # recompiles style.css on every save
npm run build        # builds style.css and style.min.css

Any other Sass compiler (Prepros, Koala, VS Code “Live Sass Compiler”) also works - compile assets/scss/style.scss to assets/css/style.css. The SCSS uses the modern @use module system (Dart Sass 1.33+).

Bootstrap is included as the precompiled bootstrap.min.css; theme styles map Bootstrap's own CSS variables onto Kovra's palette in base/_root.scss.

Animations

All motion is controlled with HTML data attributes, so you rarely need to touch JavaScript. Behaviour lives in assets/js/main.js, which is split into numbered modules (see the table of contents at the top of the file).

AttributeEffect
data-splitHeading words slide up when scrolled into view. Use data-split="hero" to play right after the preloader.
data-anim="fade-up" / "fade"Fade (and rise) into view. Siblings are staggered automatically.
data-reveal="image"Clip-path wipe reveal of an image wrapper + subtle zoom.
data-speed="0.1"Parallax on an <img> inside an overflow-hidden .media wrapper.
data-count="240"Counts up from 0 when visible.
data-highlightParagraph words light up as you scroll.
data-magnetic (optional value e.g. "0.5")Element is pulled toward the cursor.
data-cursor-text="View"The custom cursor grows and shows the label.
data-reveal-img="path.svg"On list links: a floating image follows the pointer.
data-horizontalSection with .h-scroll__track scrolls sideways while pinned (desktop).
.marquee + --marquee-speedInfinite CSS marquee; speeds up with scroll velocity. Add .marquee--reverse to flip direction.

Tuning

  • Smooth scroll: change lerp in the SmoothScroll module (lower = smoother). To disable smooth scrolling, remove the lenis.min.js script tag.
  • Preloader: durations live in the Preloader module. The full intro plays once per browser session; later page views use a quick fade.
  • Reduced motion: when the visitor's OS asks for reduced motion, smooth scroll, the cursor, preloader animation and scroll effects are switched off and all content is shown immediately.
  • No JavaScript: content stays fully visible; animation styles only apply when html.js is present.

Components

  • Buttons: .btn-kv, .btn-kv-outline, .btn-kv-sm, .btn-circle, .btn-icon, .link-arrow
  • Cards: .project-card, .service-card, .team-card, .blog-card, .testimonial, .pricing-card, .stat, .process-step
  • Lists: .hover-list, .award-list, .timeline, .work-index
  • Portfolio filter: buttons with data-filter="web" inside [data-filter-bar]; items need .filter-item and data-category="web".
  • Slider: [data-slider="id"] with a .slider__track; buttons data-slider-prev="id" / data-slider-next="id". Arrow keys work when the track is focused.
  • Pricing toggle: prices use data-price-monthly and data-price-yearly.
  • Countdown: data-date="2026-12-31T09:00:00" for a fixed launch date, or data-days="45" for a rolling demo.
  • FAQ: Bootstrap accordion restyled with .accordion-kv.
  • Showreel modal: paste your YouTube/Vimeo <iframe> inside the .ratio element of #showreel-modal in index.html.
  • Map: the contact page has a decorative map placeholder. Replace .map-placeholder's SVG with an embedded map <iframe> from your map provider.

Forms

Every form with data-validate novalidate gets accessible front-end validation (required, email, minimum length, pattern, checkboxes, selects). Error messages are written into the matching [data-error-for="field-id"] element and announced to screen readers.

Important: an HTML template cannot send email by itself. Out of the box the forms run in demo mode and show a success message. To receive submissions, point the form to a form backend or your own server script.

Add a data-endpoint attribute; the form data is sent with fetch() as multipart/form-data, and any 2xx response shows the success message:

<form class="form-kv row g-4" id="contact-form" data-validate novalidate
      data-endpoint="https://your-form-service.example/your-form-id"
      data-success="Thanks! We'll reply within one business day.">

Hosted form services (Formspree, Getform, Basin, etc.) or a PHP/Node script on your own server all work. Always validate on the server too.

Accessibility

  • Semantic landmarks (header, nav, main, footer), one h1 per page, labelled sections and a skip link.
  • All interactive elements are reachable by keyboard and have a visible focus ring. Dropdown menus open with Enter/Space and close with Escape.
  • Body text meets WCAG AA contrast in both color modes; light mode uses a darker accent for text.
  • Decorative duplicates (marquee copies, cursor, preloader) are hidden from assistive technology.
  • prefers-reduced-motion is fully respected.

Browser support

Latest versions of Chrome, Edge, Firefox, Safari (macOS & iOS) and Samsung Internet. Internet Explorer is not supported.
